How to prepare the question bank

The bank is an Excel file with one row per question. You can start from a blank template or from one with the examples on this page.

Questions with several correct answers

Write all the correct letters together in the correct column, for example AB. It is best to say so in the question («one or more answers»). Students mark on the sheet every option they think is correct.

How they are scored is chosen when configuring the exam. With correct answer AB, correct +{{ cfg.valor_bien|dec(1) }} and wrong {{ cfg.valor_mal|dec(1) }}:

Partial credit: (right − wrong) / number of correct answers, never below 0. If none is right, it counts as wrong. Blank always scores 0.

Groups and versions

Versions (A, B, C…) are created in step 2 of each exam. Each version is given the groups it uses, separated by commas. The group column of the bank says which group each question belongs to.

  • The version takes all the questions in its groups.
  • If they do not reach the number of questions in the exam, the rest are chosen at random from the questions without a group, different for each version.
  • If there are more than needed, they are chosen at random among them.
  • A version without groups takes all its questions at random from the whole bank.

With the example bank (group 1: questions 1 and 2; group 2: 3 and 4; no group: 5, 6 and 7) and an exam of {{ n_ejemplo }} questions, the versions table would show:

When printing, copies alternate versions (A, B, C, D, A…) so that neighbouring students get different exams. Each copy carries a QR code with its version, so the scanning order does not matter.

Shuffling questions and options

Each version shuffles the order of the questions and of their options (both can be turned off in the settings). Some options should not move:

  • Those starting with «All…» or «None…» (or «Todas…», «Ninguna…») stay in place automatically.
  • To fix others, write their letters in the fixed column (for example ABC if the order matters).
  • If a question has fewer than four options (true/false), leave the last ones empty: they are not printed.

Explanation of the correct answer

The explanation column is optional. If you write in it why the correct answer is correct, Aspa shows it in the review screen, below the question and its options, when the student did not get it right (wrong, partial credit, blank or pending review). It does not appear for questions answered correctly.

  • It is especially useful in review with the student mode: hovering over a wrong question, the student sees what they marked, which answer was correct and why.
  • In the answers table, wrong questions that have an explanation show the ⓘ symbol.
  • Explanations are not printed on the exam.
  • They can be added or corrected after generating the exam: just upload the bank again with the column filled in. As long as the rest of the questions do not change, the printed exam is still graded the same way.

Images

Images do not go in the Excel file: they are uploaded in step 1 of each exam («Exam images»). They are printed at the end of every exam, in the order of the list and with their caption («Image 1», «Image 2»… or any text you choose). Questions refer to them by that caption, for example «According to image 1, which kind of frame is shown at number 5?».

If you prefer to put together a composition of several images that are already labelled, upload it as a single image and leave the caption empty.

Exams in another language

Each exam has a language of the printed exam, chosen when creating it or in step 2 (Settings). Aspa translates the answer sheet, the instructions for students and the «Answer keys by version» PDF into that language. Questions are not translated: they are printed exactly as written in the bank. So if the exam is printed in English, the question bank must be in English.

Example: Erasmus students

If a group includes Erasmus students who take the exam in English, the easiest approach is to prepare two exams for the same exam session:

  1. The usual exam, in the local language, for the group.
  2. A second exam created with «Start from a previous exam» from the first one (so the versions, scoring and settings are copied), with the language of the printed exam set to English.
  3. In that second exam, upload the bank with the translated questions. It is best to keep the same id and group as in the original bank, so that versions are built the same way and the statistics are comparable.
  4. As the class list, the Erasmus students are enough (or the full list).

Each exam is printed, scanned and graded separately. If a sheet is uploaded to the wrong exam by mistake, Aspa detects it from the QR code and warns that the sheet belongs to another exam.
