How to prepare a personalised exam

One exam per student, with their name printed and without the questions they have already passed in class (quizzes, activities…). Those questions count as correct and the grade is calculated over the full exam.

A single file with two sheets

The template is an Excel file with a questions sheet (the bank, as in any exam) and a students sheet (the class list with one extra column, passed). Upload it whole in Question bank and Aspa takes the student list from the same file; there is no need to upload it separately. If you prefer two files, that also works: a list uploaded in «Class list» takes priority.

Passed questions

  • In the passed column, write the ids of the bank questions the student has already passed, separated by commas: 1, 2.
  • Those questions are removed from their exam and each counts as fully correct.
  • If the cell is empty, the student gets the full exam, still with their name printed.
  • If an id does not exist in the bank, Aspa warns you in step 1 before generating.

Versions and assignment

Versions are defined as in any exam, using the bank groups (step 2). Each student is assigned a version that contains all their passed questions; if several do, students are spread across them. Their exam is that version's questions minus the passed ones, in random order.

Spare exams

For anyone not on the list (late enrolment, change of group…) you can print spare exams: full, not personalised and with the boxes to mark the ID number, as in an exam by versions. You set how many in step 2 and they come at the end of the PDF.

Steps in Aspa

  1. Create the exam choosing the Personalised type (it can also be changed in step 2).
  2. In step 1, upload the Excel file in Question bank. A table appears with each student, their passed questions, the assigned version and how many questions they will get; check the warnings.
  3. If questions refer to images, upload them in Exam images.
  4. In step 2, define the versions, the number of questions in the full exam and the spare exams.
  5. Generate and print. The PDF is sorted alphabetically.
  6. Grading works as in any exam: the student is identified by the QR code on their sheet.
