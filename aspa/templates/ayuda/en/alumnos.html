How to prepare the student list

The list is used to put a name on each scanned sheet and to build the «Class list» sheet in the grades file, where students who did not sit the exam are marked as «Absent». In personalised exams it also states which questions are removed from each student's exam.

Download blank template Download template with examples

Two ways to do it

University class list, unchanged

Export the class list from the university system and upload it as is. The application finds the ID and full-name columns on its own (Doc. and Apellidos y nombre in the Spanish system), even if there are title rows above.

Your own template

A sheet with two columns, document and name. Useful if that list is not available or to add students by hand.

Personalised exams: the «passed» column

For personalised exams only, a third column is added, passed, with the numbers (id) of the bank questions that are removed from that student's exam because they already passed them in class, separated by commas (for example 1, 2). In exams by versions this column is ignored and may stay empty. For that student:

  • Their exam does not include those questions, and the sheet states how many they have passed.
  • Each passed question counts as fully correct, and the grade is calculated over the full exam.
  • They are assigned a version that contains all their passed questions. If there is none, Aspa warns you before generating.
  • If the cell is empty, they get the full exam with their name printed.

For personalised exams it is easier to use a single Excel file with the questions and the students: How to prepare a personalised exam.

How it is matched with the answer sheet

  • In personalised exams the student is already printed on the sheet and nothing needs to be marked. What follows applies to exams by versions and to spare copies.
  • Students write their ID number and mark only the digits, one digit per column, starting from the left (there are 10 columns).
  • The application removes the letters from the IDs in the list and compares the digits. That is why national IDs, residence cards and passports all work.
  • If a digit is mismarked or duplicated, it suggests the closest student and leaves the sheet «to review».
  • If it cannot find the student, a search box appears in the review screen to assign them by hand.

Store the ID as text in Excel (the template already does) so that leading zeros are not lost.
